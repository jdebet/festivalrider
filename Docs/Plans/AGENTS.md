# Plans — Agent rules

- New plan filenames MUST match `NNN-kebab-title.md`; numbers are monotonic and NEVER reused.
- When superseding, set the prior plan's `## Status` to `Superseded by NNN` and update the index table in `readme.md`.
- ALWAYS update the index table in `readme.md` when adding, superseding, or archiving a plan.
- Plans MUST stay dense reference prose. NEVER embed implementation snippets that belong in code.
- Successor plans MUST reference the superseded plan in their `## Context`.
